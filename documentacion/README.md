# Documentación de Capacitación — Microplast Stock Manager

**Sistema de gestión de inventario y producción para Microplast**  
Fecha de elaboración: Abril 2026

---

## ¿Qué es este sistema?

Microplast Stock Manager es el sistema de gestión interno de Microplast para controlar el inventario de materias primas (plástico por color), registrar producciones, administrar el stock de productos terminados y gestionar los despachos a clientes mediante remitos numerados.

## Manuales de Módulos

### [01 — Primeros Pasos](manuales/01_primeros-pasos.md)
Cómo acceder al sistema, iniciar sesión, recuperar contraseña, entender el menú de navegación y cerrar sesión correctamente.

### [02 — Panel Principal (Dashboard)](manuales/02_dashboard.md)
Cómo leer los indicadores clave (KPIs), interpretar las alertas de stock bajo y consultar el historial de actividad reciente.

### [03 — Producción](manuales/03_produccion.md)
Cómo registrar una producción paso a paso: seleccionar producto, elegir colores de material, ingresar cantidad y confirmar. Incluye productos multicapa.

### [04 — Inventario: Materias Primas](manuales/04_inventario-materias-primas.md)
Cómo ver el stock actual por color, agregar kilogramos, interpretar los estados de alerta y configurar umbrales.

### [05 — Inventario: Productos Terminados](manuales/05_inventario-productos-terminados.md)
Cómo consultar el stock de productos fabricados, buscar y filtrar, actualizar precios unitarios y entender el valor total por ítem.

### [06 — Despacho: Crear Remito](manuales/06_despacho-remitos.md)
Cómo completar un remito de despacho: datos del cliente y transportista, agregar ítems, generar el número de remito e imprimir.

### [07 — Historial de Remitos](manuales/07_historial-remitos.md)
Cómo buscar remitos anteriores por fecha, cliente o número, ver el detalle y reimprimir.
